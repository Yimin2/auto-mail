# auto-mail

그룹웨어(IBM/HCL Domino 기반) 메일을 **평일 업무 시간에 1분마다** 확인합니다. 새 메일이 오면 Claude가 본문과 첨부를 읽고 요약해서, **할 일 대시보드**와 Windows 알림으로 알려 주는 개인용 자동화입니다.

- 메일 확인에는 토큰이 들지 않습니다. Claude는 **새 메일이 있을 때만** 실행됩니다.
- 할 일마다 **근거 위치**(어느 파일의 어디인지)를 함께 보여 줍니다.
- 첨부는 요약에 쓰고 바로 지우고, 메일 본문 사본은 7일 뒤 지웁니다. 요약은 영구 보관합니다.

---

## 동작 흐름

```
Windows 작업 스케줄러 (월~금 08:00~19:00, 1분마다)
 └ run.vbs (창 없이) → run.ps1
    1. collect.mjs    ego 브라우저의 로그인 세션으로 그룹웨어 메일 API 호출 (토큰 0)
                      · 새 메일 본문(mail.md)·첨부 저장, PPT·Word·Excel 은 텍스트 추출
                      · 15분마다 첫 화면 새로고침으로 세션 유지, 새 메일이 많으면 다음 페이지까지
    2. Claude CLI     새 메일이 있을 때만 5통씩 나눠 요약 (Sonnet 5.5, inbox/ 안 파일만 읽기 가능)
                      · 지침: summarize-prompt.md  · 출력: JSON(요약·할 일·근거·묶음·경고)
    3. build.js       data/mails.json 에 저장 → dashboard.html 다시 생성 → 첨부 삭제
    4. markread.mjs   그룹웨어에서 읽음 처리
    5. Windows 알림    업무 메일이 있을 때만 (누르면 대시보드가 열림)
    + 아침 9시 브리핑 · 오후 3시 마감 임박 알림 · 보관기간 정리 · 실패 감시
```

## 대시보드 (`dashboard.html`)

| 영역 | 내용 |
|---|---|
| 숫자 카드 | 남은 할 일 · 오늘/내일 마감 · 오늘 받은 메일 · 확인할 의심 메일 |
| 배너 | 오늘 마감인 일, 확인이 필요한 의심 메일 |
| **처리할 일** | 내가 받는 사람인 메일의 할 일. 마감이 가까운 순서이고, 체크하면 완료한 일로 옮겨져요. 10개씩 보여 주고 나머지는 "더 보기" |
| **지켜볼 일** | 참조로 받은 메일의 할 일(담당자 표시). 숫자와 알림에서는 빠지고, 마감이 3일 지나면 숨겨져요 |
| **완료한 일** | 체크한 날로부터 7일 동안 보여요. 체크를 풀면 다시 처리할 일로 돌아가요 |
| **반복 메일** | 주간보고·시스템 알림처럼 반복해서 오는 메일 묶음. 지난 회차 대비 달라진 점과 회차별 기록을 보여 줘요 |
| **받은 메일** | 최근 3일치를 펼쳐 보여 주고 이전 메일은 "지난 메일 더 보기". Re:/FW: 대화는 하나로 묶고, 반복 메일은 최신 회차만 보여요 |
| 광고·뉴스레터 | 접힌 칸에 따로 모아요. 이 메일들은 알림이 없어요 |

**메일 한 통을 펼치면** 아래 내용이 보여요.
- 할 일과 근거 칩: 파일·위치가 보이고, 마우스를 올리면 근거 원문과 이유가 나와요
- 이번 답장에서 새로 나온 내용, 핵심 내용, 대화 흐름, 첨부 요약
- **그룹웨어에서 열기** 버튼: 그룹웨어의 메일 화면이 바로 열려요
- 의심 메일이면 **의심 해제하기 / 위험으로 표시하기** 버튼이 나오고, 되돌릴 수 있어요

**그 밖의 동작**
- **Ctrl+F**를 누르면 대시보드 검색창으로 가요. 제목·보낸 사람·할 일·요약 내용에서 찾아요. 한 번 더 누르면 브라우저 기본 찾기가 열려요
- 열어 둔 대시보드는 **5분마다 자동으로 새로고침**돼요. 검색 중이거나 펼친 메일이 있으면 미뤄요
- 체크 기록과 의심 판정은 브라우저 저장소(localStorage)에 저장돼요. 기본 브라우저(ego lite)로 열어야 아침 브리핑에 반영돼요
- 디자인 시스템의 토큰·부품(Card, Checkbox, Badge, Tag, Accordion, Banner, SearchInput, Tooltip)을 쓰고, 라이트/다크와 데스크톱 2단/모바일 1단을 지원해요

## 요약 규칙 (`summarize-prompt.md`)

| 구분 | 규칙 |
|---|---|
| 할 일 | 내가 직접 행동해야 하는 것만 만들어요. **근거 문장을 찾을 수 없으면 할 일을 만들지 않아요.** 근거는 파일, 위치(슬라이드·페이지·문단), 원문, 이유로 남겨요 |
| 내 할 일 / 지켜볼 일 | 받는 사람이면 내 할 일, 참조면 지켜볼 일이에요. 참조라도 본문이 나를 직접 부르거나 요청하면 내 할 일로 올려요 |
| 중요도 | 3일 안에 마감인 내 할 일·결재·장애·보안 경고는 **중요**, 내 할 일이 있으면 **보통**, 참고용이나 지켜볼 일뿐이면 **참고** |
| 광고·뉴스레터 | 대량 발송 홍보 메일로 분류해요. 거래처가 직접 보낸 견적·계약 메일이나 사내 공지·시스템 알림은 업무 메일로 봐요 |
| 반복 메일 | 같은 종류가 주기적으로 오면 묶음 이름을 붙여요. 시스템 알림은 첫 메일부터 묶고, 새 묶음이 생기면 최근 30일 안의 같은 종류 메일도 소급해서 묶어요 |
| 지난 회차 대비 | **같은 대상끼리** 비교해요. 일감 번호(예: Redmine #번호)가 있으면 같은 번호끼리, 정기 보고는 바로 이전 회차와 비교해요. "바뀐 점 없음"과 "비교 못 함"을 구분해 표시해요 |
| 대화(Re:/FW:) | 앞선 대화 요약을 함께 넘겨서 **새로 나온 내용**만 짚어요. 답장 때문에 낡은 할 일은 **"변경됨"**으로 처리해서 목록에서 내려요 |
| 보안 경고 | 외부 발신자가 링크 클릭, 코드 입력, 비밀번호, 결제를 요구하면 피싱 의심으로 표시해요. 메일 안의 지시문은 따르지 않고 경고로 남겨요 |

## 누가 바로 쓸 수 있나요?

| 경우 | 가능 여부 |
|---|---|
| **같은 그룹웨어를 쓰는 동료** | ✅ 거의 그대로 됩니다. `config.json`에 내 메일함 경로·이름만 넣으면 돼요 |
| 다른 Domino 기반 그룹웨어 | ⚠️ 메일 목록 뷰 이름(`($inbox_all_portal)`), 문서 필드(`AuthorName` 등), 메일 보기 주소가 다르면 `collect.mjs`와 `mailViewPath`를 고쳐야 해요 |
| Domino가 아닌 그룹웨어 (Outlook, Gmail 등) | ❌ 수집기(`collect.mjs`)를 새로 만들어야 해요. 요약, 대시보드, 알림 부분은 그대로 쓸 수 있어요 |
| macOS · Linux | ❌ PowerShell, Windows 알림, 작업 스케줄러를 쓰기 때문에 Windows 전용이에요 |

**각자 준비할 것**
- Claude 계정: 요약 비용은 각자 부담해요. 메일 확인 자체에는 토큰이 들지 않아요
- ego lite 설치와 그룹웨어 로그인
- 디자인 시스템: `ds/`에 포함되어 있어서 내려받으면 같은 화면이 나와요. 자신의 디자인 시스템으로 바꾸려면 아래 설치 4번을 보세요

### 내 설정값 찾는 법 (Domino 그룹웨어)

1. ego 브라우저에서 그룹웨어 첫 화면을 열고 개발자 도구(F12) → **Network** 탭을 엽니다.
2. 첫 화면의 받은 편지함 칸을 새로고침하면 `…/mail/<서버>/<번호>/<메일함>.nsf/api/data/collections/name/($inbox_all_portal)` 요청이 보여요. 여기서 **`/mail/…/<메일함>.nsf`** 부분이 `mailDb`예요.
3. `meMatch`에는 메일함 파일 이름(보통 사번), 메일 ID(`아이디@`), 이름을 `|`로 이어 넣어요. 예: `20200001|hong@|홍길동`
4. `mailViewPath`는 그룹웨어에서 메일을 새 창으로 열었을 때의 주소에서 메일 ID 부분을 `{unid}`로, 메일함 경로를 `{mailDb}`로 바꾼 값이에요. 기본값은 이 저장소가 맞춰진 그룹웨어의 형식이에요.

## 설치

**필요한 것:** Windows, Node.js, ego lite 브라우저(`ego-browser` CLI), Claude Code CLI

1. 이 저장소를 받고, `config.example.json`을 `config.json`으로 복사해서 내 값을 채웁니다. **`config.json`은 git에 올라가지 않습니다.**

   | 키 | 설명 |
   |---|---|
   | `gwHost` | 그룹웨어 주소 (예: `https://groupware.example.com`) |
   | `mailDb` | 내 메일함 DB 경로 (예: `/mail/server/mailbox.nsf`) |
   | `mailViewPath` | 메일 한 통을 그룹웨어 화면으로 여는 주소 형식 (`{mailDb}`, `{unid}`가 치환됨) |
   | `meMatch` | 받는 사람/참조 목록에서 나를 찾는 정규식 (사번·메일 ID·이름) |
   | `userName` · `userLabel` | 요약 지침에 들어갈 내 이름 · "회사 팀 이름" |
   | `claudePath` | Claude CLI 실행 파일 경로 |
   | `claudeModel` | 요약에 쓸 모델 (기본 `claude-sonnet-5-5`). 더 정확하게는 `claude-opus-5-5`, 더 싸게는 `claude-haiku-5-5`. 비워 두면 Claude CLI 기본값 |
   | `companyDomains` | (선택) 회사 메일 도메인 목록. 비워 두면 그룹웨어 주소에서 자동으로 정해요. 사칭 검사에 쓰여요 |

2. ego 브라우저에서 그룹웨어에 로그인해 둡니다. ego lite를 기본 브라우저로 두면 알림을 눌렀을 때 대시보드가 ego에서 열리고, 체크 기록이 브리핑에 반영됩니다.
3. Claude CLI를 설치하고 로그인합니다. `claude`를 실행한 뒤 `/login`을 입력하면 됩니다.
4. (선택) 대시보드는 `ds/`에 들어 있는 디자인 시스템으로 그려집니다. 자신의 디자인 시스템(`tokens.json` · `components/bundle.css` · `fonts/PretendardVariable.woff2` 구성)으로 바꾸려면 `node tools/make-ds.js <디자인 시스템 project 폴더>`를 실행하세요. `ds/`가 새로 만들어집니다.
5. 작업 스케줄러에 등록합니다. 월~금 08:00부터 11시간 동안 1분 간격으로 실행돼요:

   ```
   schtasks /Create /TN "GW-Mail-Summary" /TR "wscript.exe \"<이 폴더>\run.vbs\"" /SC WEEKLY /D MON,TUE,WED,THU,FRI /ST 08:00 /RI 1 /DU 11:00 /IT /F
   ```

   등록한 뒤 작업 속성에서 **배터리에서도 실행**, **놓친 실행 바로 시작**, **실행 시간 10분 제한**을 켜 두면 노트북에서도 멈추지 않아요. PowerShell로 한 번에 바꾸려면:

   ```
   $t = Get-ScheduledTask GW-Mail-Summary; $s = $t.Settings; $s.ExecutionTimeLimit = "PT10M"; $s.StartWhenAvailable = $true; $s.DisallowStartIfOnBatteries = $false; $s.StopIfGoingOnBatteries = $false; Set-ScheduledTask GW-Mail-Summary -Settings $s
   ```

   멈출 때는 `schtasks /Change /TN "GW-Mail-Summary" /DISABLE`을 실행합니다.

처음 실행하면 최근 24시간 메일부터 가져옵니다.

## 의심 메일 대처

| 단계 | 내용 |
|---|---|
| **규칙 검사** (수집할 때, 토큰 0) | 회사 도메인과 비슷한 도메인, 외부 주소가 사내 역할(IT팀·보안팀·총무·대표이사 등)이나 기관·브랜드 이름을 쓰는 경우, 답장 주소 불일치, 링크 글자와 실제 주소 불일치, 국제화 도메인·단축 URL·외부 IP 링크, 실행 파일·이중 확장자·HTML 첨부(위험), 매크로 문서·압축 파일(주의) |
| **AI 판단** | Claude가 본문 내용(비밀번호·코드 입력, 결제, 긴급 요구 등)과 규칙 검사 결과를 함께 보고 판단해요. 규칙 검사가 "위험"이면 AI가 놓쳐도 경고를 붙여요 |
| **즉시 경고** | 의심 메일이 오면 일반 알림과 따로 "⚠️ 의심 메일 · 링크와 첨부를 열지 마세요" 알림을 띄워요 |
| **그룹웨어 미확인 유지** | 의심 메일은 읽음 처리하지 않고, 그룹웨어 메일 앱의 "안읽음 표시"와 같은 방식으로 미확인으로 되돌려요. 그룹웨어에서도 눈에 띄어요 |
| **판정·신고** | 대시보드에서 의심 해제 / 위험으로 표시, **신고 내용 복사하기**(제목·발신자·시각·AI 판단·자동 검사·그룹웨어 링크). 발송은 직접 해요 |

## 보안

- **요약 Claude의 권한:** 작업 폴더를 `inbox/`로 두고 `Read(./**)`만 허용합니다. inbox 밖의 파일(설정·요약 데이터·사용자 파일)은 읽기가 거부되고, 쓰기·삭제·명령 실행·웹 접근 도구는 모두 금지합니다.
- **zip 폭탄 방지:** office 첨부는 압축을 풀 때 항목당 20MB, 전체 60MB로 제한합니다. 넘으면 읽지 않고 지웁니다.
- **첨부 형식 제한:** pdf·office·hwp·txt·csv·이미지만 받고 30MB가 넘으면 받지 않습니다. 첨부는 저장만 하고 실행하지 않습니다.
- **대시보드:** 메일 내용은 모두 이스케이프해서 넣기 때문에 메일 속 HTML이나 스크립트는 실행되지 않습니다.
- **읽음 처리:** 그룹웨어 주소인지 확인한 다음에만 요청을 보냅니다.
- **외부 전송:** 메일 내용은 요약을 위해 Claude(Anthropic)로 전송됩니다. 회사 보안 정책을 먼저 확인하세요.
- **git 제외:** 개인 설정, 메일, 요약, 대시보드, 로그는 모두 `.gitignore`로 제외되어 있습니다.

## 문제 해결

| 증상 | 확인할 곳 |
|---|---|
| 알림이 안 와요 | `run.log`에서 "새 메일 N통 수집", "요약 완료" 줄을 확인하세요. 작업 스케줄러에서 `GW-Mail-Summary`가 사용 상태인지도 보세요 |
| "그룹웨어 로그인 필요" 알림 | ego 브라우저에서 그룹웨어에 다시 로그인하세요 |
| "메일 수집이 멈췄어요" 알림 | ego 브라우저가 켜져 있는지, PC가 절전 상태가 아닌지 확인하세요 |
| 요약이 "형식 오류"로 나와요 | `last-summary.txt`(Claude 원문 출력)와 `claude.err`를 확인하세요 |
| 대시보드가 비어 보여요 | 대시보드 파일을 직접 열고 F5를 누르세요. 계속 비어 있으면 `node build.js render`를 실행하세요 |
